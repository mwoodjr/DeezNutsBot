## LinkedIn project title

Discord Bot Development & Infrastructure

## LinkedIn description

Built a JavaScript Discord bot with slash commands, event handlers, and MongoDB-backed user and server statistics. Used discord.js and Mongoose for the application, with hybrid sharding to organize Discord connections across separate Node.js processes.

The project gave me hands-on experience with API integrations, database schemas, configuration management, and troubleshooting an application with several moving parts. I also prepared Docker deployment files and moved sensitive configuration into environment variables as part of preparing the code for public release.
